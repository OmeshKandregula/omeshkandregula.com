What I changed, and why

Four decisions. The first came from the people who would use it.

01

Ratings and tiers, not one national forecast.

One national number per film

→A film rating, plus a tier for every theater

The sponsor's planners told us a national number gets films dropped where they would sell.

02

Plans are decided per theater.

Rating × tier lookup table

→Play, Weekends or Skip, decided theater by theater

The table contradicted itself, so we stopped using it.

03

Re-releases say what the model does not know.

Score an old film like a new one

→Flag it: No cast data for this film

A warning is more useful than a confident number built on missing inputs.

04

A name is not a film.

Search: "Ranbir"

→Person, not a film. Not scored.

Verified against Wikidata

Buzz search takes any text. Identity is checked before anything gets a score.

03

System Architecture

Three stages, free and public sources only

1. Ingest

Arctic Shift Reddit archive Wikipedia pageviews YouTube Data API TMDB API Census ACS OpenStreetMap competitors

2. Model

Python. A shrinkage model for theaters, a ridge model for films, validated on a time split.

3. Deliver

Next.js on Vercel with Google sign-in, an Excel tool, and daily and weekly jobs on GitHub Actions.
